# Массовое выбытие ОС из файла (BAPI_ASSET_RETIREMENT_POST)

Утилита для массового выбытия (списания) основных средств по загружаемому Excel-файлу —
когда нужно вывести из эксплуатации сразу список ОС и не прокликивать каждое в `ABAVN`/`ABAON`.

## Как работает

1. **Вход** — Excel-файл (загрузка через `ALSM_EXCEL_TO_INTERNAL_TABLE`), колонки:
   БЕ (BUKRS), единица оборудования (EQUNR), основной номер ОС (ANLN1), субномер (ANLN2),
   вид движения (BWASL), дата проводки (BUDAT), сумма (ANBTR), процент выбытия (PROZS).
2. Данные обогащаются мастер-данными для контроля: класс и название ОС из **ANLA**,
   текст единицы оборудования из **EQKT** (ненайденные помечаются).
3. **Превью в ALV** (структура `ZSR2R_AA_MASS_RET`, вывод через `REUSE_ALV_GRID_DISPLAY_LVC`),
   по даблклику — проваливание в карточку значений ОС `AW01N`.
4. По кнопке **POST** для каждой строки:
   - `BAPI_ASSET_RETIREMENT_POST` — проводка выбытия (частичное по сумме/проценту или полное);
   - `BAPI_EQUI_CHANGE` — очистка ссылки единица оборудования ↔ ОС;
   - `BAPI_TRANSACTION_COMMIT`. Номер созданного документа пишется в строку отчёта.

## Замечания

- Валюта суммы захардкожена (`RUB`) — при переносе в другую систему поправить.
- Структуру ALV `ZSR2R_AA_MASS_RET` нужно создать в SE11 (в репозитории её описания нет —
  состав полей виден из кода загрузки).
