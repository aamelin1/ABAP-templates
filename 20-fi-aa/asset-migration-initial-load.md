# Миграция ОС — начальная загрузка остатков из файла (BAPI_FIXEDASSET_OVRTAKE_CREATE)

Комплект для миграции (начальной загрузки остатков) основных средств из Excel-файла —
альтернатива ручному вводу через `AS91`. Ключевая идея: соответствие «колонка файла → поле
BAPI-структуры» задаётся **настроечной таблицей**, а не хардкодом, поэтому состав загружаемых
полей меняется без правки программы.

## Состав комплекта

| Объект | Назначение |
|---|---|
| `ZR2R_AA_MIGRATION` (+ инклуд `_F01`) | Основной отчёт: загрузка файла, маппинг, превью в ALV, разноска |
| `ZSR2R_MIGRATION_MAP` (структура SE11) | Контейнер всех BAPI-структур: `BAPI1022_KEY`, логические группы (GENERALDATA, POSTINGINFORMATION, TIMEDEPENDENTDATA, ALLOCATIONS…), российская локализация `BAPI1022_GLO_RUS_*` (имущественный/транспортный налог), и по каждой области оценки — `BAPI1022_DEP_AREAS` + `BAPI1022_CUMVAL` |
| `ZTR2R_AA_MIGRCUS` (таблица) + `ZVR2R_AA_MIGRCUS` (ракурс ведения) | Настройка маппинга: область оценки (AFABE) + имя BAPI-структуры + имя поля + порядковый номер колонки файла; ракурс подтягивает из DD03L/DD01L тип данных и конверсионную подпрограмму (CONVEXIT) |

## Как работает

1. **Настройка** (`SM30` → `ZVR2R_AA_MIGRCUS`): для каждой колонки Excel указывается целевая
   BAPI-структура/поле и область оценки. Конверсия значений (ALPHA, даты, суммы) выполняется
   автоматически по CONVEXIT из словаря.
2. **Загрузка файла** — `ALSM_EXCEL_TO_INTERNAL_TABLE`, раскладка значений по структурам
   согласно настройке.
3. **Превью в ALV** — контроль замапленных значений до разноски.
4. **Разноска** — по каждой строке `BAPI_FIXEDASSET_OVRTAKE_CREATE` (создание карточки ОС
   с накопленными значениями переноса по областям оценки) + `BAPI_TRANSACTION_COMMIT`.

## Замечания

- Перед загрузкой должна быть выполнена настройка переноса старых данных FI-AA
  (дата переноса и статус — `FAA_CMP` / `FAA_CMP_LDT`).
- Области оценки в структуре `ZSR2R_MIGRATION_MAP` заведены под конкретный план
  амортизации (01/03/10/30/31…) — под другой ландшафт состав областей скорректировать.
